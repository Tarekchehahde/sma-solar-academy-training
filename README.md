# SMA Solar Academy Training App

An interactive German-English technical vocabulary trainer for solar inverter installation, branded for SMA Solar Technology.

![SMA Logo](https://img.shields.io/badge/SMA-Solar%20Technology-c00d0d?style=for-the-badge)

## Features

### 📚 Vocabulary Training
- 70+ technical terms with German, English, pronunciation guides
- Categories: Electrical, Components, Installation, Measurements, Safety, SMA Products
- Tap-to-reveal flashcards
- Search functionality

### ⚡ Interactive Power Flow Diagram
- Realistic SMA system layout (Sun → Panels → Inverter → Grid)
- Visual representation of DC, AC, and Data flows
- Battery storage branch with SMA Sunny Boy Storage
- Data/Communication section (Data Manager M, Sunny Portal, Energy App)
- Click any component for detailed terminology

### 🔄 Flashcard Mode
- Interactive 3D flip cards
- Track progress and mark known terms
- Shuffle feature

### ❓ Quiz Mode
- 15-question multiple choice tests
- Score tracking with progress bar
- Immediate feedback in German and English

### 📊 System Diagrams
- SMA product lineup (Sunny Tripower, Sunny Boy Storage, Sunny Home Manager)
- Component details with German/English terms

### 🔧 Installation Steps
- 8-step installation process
- Key German terms for each step

### ⚠️ Safety Section
- Critical safety warnings in German
- PPE terms, hazard warnings

### 🛠️ Tools Section
- Common installation tools
- German names with English translations

## SMA Products Covered

- **Sunny Tripower** - String Inverter
- **Sunny Boy** - Single-Phase Inverter
- **Sunny Boy Storage** - Battery Inverter
- **Sunny Home Manager** - Energy Manager
- **Sunny Portal** - Cloud Monitoring
- **SMA Energy App** - Mobile App
- **Data Manager M** - Data Logger
- **Speedwire** - Communication Protocol

## Installation

### Web Version
Simply open `index.html` in any modern browser.

### Android APK
Download the APK from the releases section and install on your Android device.

## Building the APK

```bash
# Install dependencies
npm install

# Build APK using Cordova
npm run build:android
```

## Technology Stack

- HTML5, CSS3, JavaScript (Vanilla)
- Apache Cordova (for APK generation)
- Responsive design optimized for landscape mode
